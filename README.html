📐 Mathematical Formulations for Consecutive Class Recovery

Given total conducted classes T, attended classes A, and benchmark threshold P_target = 0.75 (75%):

Case 1: Student is in Shortage (< 75%)

Upcoming consecutive classes x required to reach or exceed 75%:

x = ceil( (0.75 * T - A) / 0.25 ) = ceil( 3*T - 4*A )

Example: If T=16, A=10 (Attendance = 62.5%): x = ceil(3*16 - 4*10) = 48 - 40 = 8 upcoming consecutive classes required.

Case 2: Student is Eligible (≥ 75%)

Safe miss buffer (classes student can miss without dropping below 75%):

m = floor( (A / 0.75) - T ) = floor( (4*A - 3*T) / 3 )

🛠️ Offline Troubleshooting for Other Machines / Agents

  • Port 8501 already in use? Run on an alternate port:
    streamlit run app.py --server.port=8502
  • Headless server mode: If running in Docker or automated CI/CD:
    streamlit run app.py --server.headless=true --server.port=8501
  • Windows Defender asyncio constraint: In restricted environments, set WindowsSelectorEventLoopPolicy before starting asyncio tasks.
